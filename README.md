# MarkdownFree

**极轻量、免安装、不上云的 Markdown 阅读与行内点评工具。**

> 打开浏览器，就是你的 Markdown 阅读器。无需安装桌面应用，无需注册账号，无需上传文件到任何服务器——你的文档始终留在你的电脑上。

---

## 💡 它解决了什么问题？

阅读 `.md` 文件，你可能正在经历这些痛苦：

| 痛点 | 传统方案 | MarkdownFree |
|------|---------|-------------|
| 需要安装独立应用 | Typora、Obsidian、VS Code… | ❌ 不需要，浏览器即开即用 |
| 文件必须上传到云端 | HackMD、Notion、语雀… | ❌ 不需要，100% 本地离线 |
| 想做批注要切换工具 | 截图 + 备忘录 / 另起文档 | ❌ 不需要，划词即批注，直接嵌入原文 |
| 缺少目录导航 | 手动搜索标题 | ❌ 不需要，自动生成可折叠大纲 |
| 公式/图表渲染要配环境 | 装 LaTeX 发行版、配 Node.js… | ❌ 不需要，LaTeX + Mermaid 开箱即用 |

**一句话：MarkdownFree 让你用最低成本获得最优雅的 Markdown 阅读体验。**

## ✨ 为什么它与众不同？

### 🚫 零门槛

- **不用装 App** — 只是一个 Chrome 扩展，即装即用
- **不用注册账号** — 没有登录、没有云端、没有订阅
- **不用上传文件** — 你的 Markdown 文件始终在你的本地磁盘上，隐私零泄露

### 📝 行内点评系统

这是 MarkdownFree 最独特的功能。划词 → 写批注 → 点评以标准格式直接嵌入 `.md` 文件：

```markdown
这是一段文本，其中==被点评的内容==<!-- cmt: 你的批注会像这样嵌入原文 -->会被高亮显示。
```

- 点评数据 **不依赖任何数据库**，直接写入 Markdown 源文件
- 任何编辑器打开 `.md` 都能看到批注（兼容性极佳）
- 支持 **File System Access API** 一键写回原文件，也可降级为下载覆盖

### 🧭 智能导航栏

- 自动解析所有标题，生成 **可折叠的多级大纲目录**
- 滚动时自动高亮当前章节（Scroll Spy）
- 支持展开层级筛选（仅看 H1 / 展开到 H3 等）
- 目录栏宽度可拖拽调节，偏好自动记忆

### 🎨 精致的阅读体验

- **深色 / 浅色主题** 一键切换（按 `T`），护眼配色
- **中英文字体独立设置** — 分别选择中文字体（黑体 / 楷体 / 宋体）和英文字体（Inter / Georgia / Fira Code）
- 正文字号可调，排版偏好自动持久化
- 毛玻璃背景、微动画、优雅过渡——不是简陋的渲染，而是沉浸式阅读

## 🚀 安装

### 方式一：Chrome Web Store（推荐）

> 🚧 即将上线 Chrome Web Store，敬请期待。

### 方式二：本地开发者模式安装

1. **下载源码**

   ```bash
   git clone https://github.com/hansonwong310/MarkdownFree.git
   ```

2. **打开 Chrome 扩展管理页面**

   在地址栏输入 `chrome://extensions/` 并回车。

3. **开启开发者模式**

   打开页面右上角的 **「开发者模式」** 开关。

4. **加载扩展**

   点击 **「加载已解压的扩展程序」**，选择刚才下载的 `MarkdownFree` 文件夹。

5. **允许访问本地文件**（重要⚠️）

   在扩展卡片上点击 **「详情」**，找到 **「允许访问文件网址」** 并开启，否则无法渲染本地 `.md` 文件。

## 📖 使用

安装完成后，使用非常简单：

1. **将 `.md` 文件拖入 Chrome 浏览器**，或通过 `file:///` 协议直接打开
2. MarkdownFree 会自动接管渲染，呈现优雅的阅读界面
3. **划选文字** → 点击浮出的 💬 按钮 → 输入批注 → 点击确定
4. 右下角点击 💾 按钮将修改保存回原文件

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `T` | 切换深色 / 浅色主题 |
| `O` | 展开 / 折叠左侧目录栏 |
| `Ctrl/⌘ + S` | 保存修改到本地文件 |

## 🔒 隐私承诺

- **零网络请求** — 扩展不发送任何数据到外部服务器
- **零后端依赖** — 没有服务器，没有 API，没有数据收集
- **完全离线可用** — 断网也能正常使用全部功能
- 所需的唯一权限是 `storage`（用于保存你的主题、字体等本地偏好）
